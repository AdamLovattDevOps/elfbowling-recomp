Elf Bowling (native port) for Windows x64

This package does not include the game's data. On first run it asks for your copy of the
original "Elf Bowling.exe" (NStorm, 1999, freeware) and keeps a checked copy in
%APPDATA%\NStorm\Elf Bowling\. You can also put Elf Bowling.exe next to elfbowl.exe, run
elfbowl.exe "C:\path\to\Elf Bowling.exe", or set ELFBOWL_EXE. Alt+Enter toggles full screen.
